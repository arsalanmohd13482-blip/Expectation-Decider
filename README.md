# 📊 Expectation Decider Model

> **A probability-based analytical framework for understanding student exam success patterns.**

## 📌 Project Overview

The **Expectation Decider Model** analyzes a simulated cohort of **200 students** to understand exam success using probability and statistical concepts.

The analysis focuses on **study hours, attendance, group discussion participation, previous test scores, and final exam outcomes**.

## 🎯 Objectives

- Calculate basic probabilities from student data
- Compare empirical and theoretical probability
- Apply the **Binomial Distribution**
- Analyze relationships using **Venn Diagrams**
- Calculate joint and conditional probabilities
- Identify event dependency and mutual exclusivity
- Apply **Bayes' Theorem** to estimate exam success

## 🧠 Concepts Covered

| Concept | Purpose |
|---|---|
| Foundational Probability | Analyze basic student events |
| Empirical & Theoretical Probability | Compare observed and assumed probabilities |
| Binomial Distribution | Model the number of students passing |
| Venn Diagram | Analyze overlap between study hours and attendance |
| Contingency Table | Examine group discussion vs exam outcome |
| Conditional Probability | Estimate passing probability given discussion participation |
| Independence | Determine whether events are related |
| Mutual Exclusivity | Check whether events can occur together |
| Bayes' Theorem | Estimate passing probability given high attendance |

## 📊 Key Results

- **93%** of students passed the simulated exam.
- Expected number of passing students out of 3: **2.79**.
- **74 students** had both study hours above 10 and attendance above 80%.
- **P(Pass | Group Discussion = Yes) ≈ 90.29%**.
- Group discussion and passing were identified as **dependent events**.
- Using the assumed Bayes parameters, **P(Pass | High Attendance) = 77.78%**.
